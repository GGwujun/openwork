authSessions Map (服务器内存):
  key: sessionId (uuid)
  value: {
    id: sessionId,
    status: 'pending' | 'authorized',
    code: null | actual_code,
    createdAt: timestamp
  }

wsConnections Map (服务器内存):
  key: sessionId (uuid)
  value: WebSocket 连接对象

WebSocket 消息类型:
  Client → Server:
    { type: "init", sessionId }
    { type: "ping" }
    { type: "pong" }
  
  Server → Client:
    { type: "connected" }
    { type: "auth_code", code, state }
    { type: "ping" }
    { type: "pong" }

## 🎯 关键设计决策

**Q: 为什么用 WebSocket 而不是长轮询？**
A: 实时性更好，服务器可以主动推送，减少网络开销。

**Q: 为什么服务端存储 session 而不是客户端？**
A: 安全考虑，防止客户端篡改状态；支持断线重连。

**Q: session 5分钟过期合理吗？**
A: 企业微信扫码登录通常30秒内完成，5分钟足够容错。

**Q: 如果 WebSocket 断开会怎样？**
A: 授权码会暂存，客户端重连后会立即收到。
