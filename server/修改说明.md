## 🔧 企业微信配置

在企业微信后台配置可信域名：
1. 可信域名：`your-domain.com`
2. 回调URL：`https://your-domain.com/auth/callback`
3. 网页授权：JS-SDK、登录授权

## 📋 API 说明

### GET /api/login-url
获取企业微信登录URL

**响应：**
```json
{
  "success": true,
  "data": {
    "sessionId": "uuid",
    "loginUrl": "https://open.weixin.qq.com/...",
    "expiresIn": 300
  }
}
```

### WebSocket 连接
连接：`ws://your-domain:7878`

**发送：**
```json
{"type": "init", "sessionId": "uuid"}
```

**接收：**
```json
{"type": "auth_code", "code": "xxx", "state": "uuid"}
```

### GET /auth/callback
企业微信OAuth回调（自动处理）

## 🚀 测试流程

1. 桌面应用连接 WebSocket
2. 调用 `/api/login-url` 获取二维码
3. 用户扫码
4. 企业微信回调到服务器
5. 服务器通过 WebSocket 推送 code 到桌面应用
6. 桌面应用用 code 换取用户信息
7. 登录完成！

## ⚠️ 注意事项

- 生产环境建议使用 Redis 存储 session
- WebSocket 连接需做身份验证（生产环境）
- 记得配置 HTTPS（Let's Encrypt 免费证书）

## 🆘 问题排查

**WebSocket 连不上？**
- 检查防火墙是否放行 7878 端口
- 检查 nginx 是否正确转发 WebSocket

**收不到回调？**
- 检查企业微信可信域名配置
- 检查回调 URL 是否正确

**授权码推送失败？**
- 检查 sessionId 是否匹配
- 检查 WebSocket 是否已连接
